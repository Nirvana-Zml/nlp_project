# 评审清单

评审时逐项核对。缺证据写「退回」，并指出要补的文件。不要根据记忆填写数字。

## 硬门槛

- README 中的复现命令已在新进程跑通，主指标能从 `outputs/` 重算
- 计划、评审、报告中的每个关键数字都能在 csv、json 或 log 中找到同一值
- 测试集、种子、划分清单在看到分数后没有改动
- 词典与少样本示例没有读取 tune/test 的实体
- 提交物不含权重、checkpoint、原始数据、虚拟环境、API Key

任一条失败：结论写「退回」。跑不通对应源码项 0 分、总分不超过 25。数字对不上对应实验项减半。

## 评分项

| 项 | 分值 | 本步要留下的证据 |
| --- | ---: | --- |
| 选题与方案设计 | 5 | 可检验的成功判据；本步不做 RAG/LoRA 的理由已在计划中 |
| 进度与工作量 | 5 | 日期、命令、日志、预测文件 |
| 源码与可复现 | 12 | 外置配置、种子 42、一条重算命令、依赖说明 |
| 实验与评估 | 12 | 同一测试集上的基线与大模型；口径写明左闭右开；至少一组参数对比；至少 3 类错误归因 |
| 报告与录屏 | 6 | 八节对应；表从图或 CSV 来；录屏分镜含难例且不超过 2 分钟 |
| 个人贡献 | 5 | 产出文件与报告第⑧节一致；比例留给人填写 |

## 拉分最低线

- 失败样例至少 3 个：输入、输出、归因、改进
- 参数对比至少 1 组，选择发生在调参集，测试集只评一次
- 每条参与比较的方法有平均延迟、输入 token 数、输出 token 数；本地模型注明无 API 单价
- 原理点至少 3 个绑在实验上：子词切分与边界、BIO 与实体级口径、提示与监督微调

## 结论用语

只允许「待人确认」或「退回」。用户明确接受之前，不写「本步完成」或「本轮闭环」。
