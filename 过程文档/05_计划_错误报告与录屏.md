### 失败样例

脚本 `scripts/export_error_examples.py` 只读预测，写出 `outputs/errors/examples.json`。不调用模型，不改预测文件，不读调参集预测。

三元组是 `(start_idx, end_idx, type)`。区间按左闭右开 `[start_idx, end_idx)`。两条区间相交是指 `start_a < end_b` 且 `start_b < end_a`。

| 顺序 | 类别 | 文件 | 判定 |
| --- | --- | --- | --- |
| 1 | 解析失败 | `outputs/predictions/qwen_3b_one.json` | `parse_ok` 为 false，且 `gold` 非空 |
| 2 | 边界错误 | `outputs/predictions/bert_bio.json` | 存在一对 gold 与 pred：`type` 相同，区间相交，`start_idx` 或 `end_idx` 不同 |
| 3 | 类型错误 | `outputs/predictions/bert_bio.json` | 存在一对 gold 与 pred：`start_idx` 与 `end_idx` 相同，`type` 不同 |

同一条 BERT 文档若同时符合边界错误和类型错误，只进入类型错误候选。边界错误候选排除这些文档。

某一类在指定文件中为 0 条时，只替换该条，仍取该定义下最小的 `source_index`，且不与已选的 `method` + `source_index` 重复。后备顺序：

1. 无效实体：`outputs/predictions/qwen_3b_one.json`。`parse_ok` 为 true，且 `invalid_entities` > 0。
2. 表面不一致：`outputs/predictions/qwen_3b_one.json`。`surface_mismatches` > 0，且 gold 与 pred 的严格三元组集合不同。
3. 边界错误：`outputs/predictions/dictionary_longest.json`，判定与上表相同。
4. 类型错误：`outputs/predictions/dictionary_longest.json`，判定与上表相同。
5. 解析失败：先 `outputs/predictions/qwen_3b_zero.json`，再 `outputs/predictions/qwen_3b_three.json`。判定与上表相同。

替换后仍不足 3 条就停止。把已找到的条数写入 `过程文档/05_数据结果.md`。不放宽判定，不去调参集里找。

输出字段：

- Qwen：`text`、`gold`、`pred`、`raw_output`。无效实体不在 `pred` 里。脚本用与 `src/models/qwen_prompt.py` 中 `parse_model_output` 相同的规则，从 `raw_output` 标出被丢弃的对象，写入样例的 `discarded`。不回写预测文件。
- BERT：`text`、`gold`、`pred`、`token_pred`。没有 `raw_output`，模型输出记为 `token_pred`。
- 词典：`text`、`gold`、`pred`。没有 `raw_output` 和 `token_pred`，输出记为 `pred`。

每条还保存 `method`、`prediction_file`、`source_index`、`category`。`attribution` 和 `improvement` 写成空字符串。表面不一致的计分实体仍是切片后的 `pred`；样例同时保留 `raw_output` 和 `pred`。

### 报告表格

主测试表和调参集表分开。调参集的 F1 不写入主测试表。

主测试表的行和文件：

| 行 | 文件 |
| --- | --- |
| `dictionary_all`、`dictionary_longest` | `outputs/metrics/dictionary_baseline.csv` |
| `bert_bio_token`、`bert_bio_entity` | `outputs/metrics/bert_bio.csv` |
| `qwen_3b_zero`、`qwen_3b_three` | `outputs/metrics/qwen_3b.csv` |
| `qwen_3b_one` | `outputs/metrics/qwen_3b_one.csv` |

列是 `method,precision,recall,micro_f1,tp,fp,fn`，再加上平均延迟、平均输入 token、平均输出 token。延迟和 token 只从成本文件抄：

| 行 | 成本文件 | 字段 |
| --- | --- | --- |
| `qwen_3b_zero`、`qwen_3b_three` | `outputs/metrics/qwen_3b_cost.json` | `mean_latency_sec`，`mean_input_tokens`，`mean_output_tokens` |
| `qwen_3b_one` | `outputs/metrics/qwen_3b_one_cost.json` | 同上 |

词典两行和 BERT 两行没有成本文件，这四格留空，不估算。表下写明本地推理无 API 单价，出处是 `outputs/logs/qwen_3b.log` 和 `outputs/logs/qwen_shot_count.log` 的 `api_unit_price=none`。

另起一张主测试计数表，只抄 Qwen 成本文件里的 `parse_failures`、`invalid_entities`、`surface_mismatches`。这三列不并进 F1 表。

调参集表单独成节，标题写明是 1,500 条调参集，不是主测试。行是 `qwen_shot_count_tune.csv` 的 `qwen_shot_0`、`qwen_shot_1`、`qwen_shot_3`。延迟和 token 抄 `outputs/metrics/qwen_shot_count_cost.json` 的同名字段。入选条数抄 `outputs/metrics/qwen_shot_count_selection.json` 的 `selected_shots`。表下不写哪一条更好。
