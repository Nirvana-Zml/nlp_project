# 04 计划：提示数量对比

**状态：** 已交付  
**日期：** 2026-10-15  
**对应评分项：** 实验与评估（一组参数对比，选择发生在调参集）、进度与工作量（延迟和 token）、源码与可复现（外置配置、固定示例和种子）

## 本步做

在调参集上比较 0、1、3 条示例。生成配置和提示正文与第 3 步相同，只改变示例条数。用调参集的严格实体级 Micro-F1 选定一条，主测试不重跑已经评过的零样本和三样本。

1. 模型、4bit NF4、double quant、float16、`temperature=0`、`do_sample=false`、`max_new_tokens=1536`、`repetition_penalty=1.0`、`batch_size=1`、种子 42，都与 `configs/qwen_3b.yaml` 相同。加载失败就停止，不换精度，不缩小调参集。
2. 提示正文使用 `configs/qwen_3b.yaml` 里的 `prompt_template`，不改措辞。
3. 示例仍按第 3 步的规则从 `data/processed/train.json` 取出：有实体的样本按 `source_index` 排序，`random.Random(42)` 打乱。零样本不用示例。单样本只用打乱后的第 1 条，即 `3949`。三样本仍是 `3949`、`5340`、`1237`，顺序不变。
4. 三种条数都在 `data/processed/tune.json` 的 1,500 条上各生成一次。严格实体级 Micro P/R/F1 与主测试相同。调参集唯一金标三元组的 `TP+FN` 必须是 8147。中断后可以续跑尚未写完的预测，已完成的样本不重新生成。三种调参集预测都完整之前不做选择，也不把 1,500 条改成子集。
5. 程序在三种调参集预测都完整、并写出调参集 CSV 之后再选择。选择指标是该 CSV 里 6 位小数的严格实体级 Micro-F1，更高者入选。并列时取得示例更少的一条。选择时不读取主测试预测，也不读取 `qwen_3b.csv`。
6. 选择一旦写出，入选条数不再改。`qwen_shot_count_selection.json` 在任何新的主测试生成之前，只写入入选条数、三行调参集分数，以及主测试分数将从哪个文件读取。零样本入选时出处是 `outputs/metrics/qwen_3b.csv` 的 `qwen_3b_zero` 行，三样本入选时是同一文件的 `qwen_3b_three` 行；读到该行后把主测试数字填进选择文件，不重新生成。单样本入选时，出处先写成 `outputs/metrics/qwen_3b_one.csv`，等该次主测试生成结束并写出 CSV 后，再把主测试数字填进选择文件。单样本才在 `data/processed/test.json` 的 1,000 条上生成一次，`TP+FN` 必须是 4877。这次生成若中断，只续跑未完成的样本。
7. 记录调参集上每种条数的平均延迟、平均输入 token、平均输出 token。单样本入选并完成主测试生成后，另把该次的平均延迟和 token 写入 `outputs/metrics/qwen_3b_one_cost.json`。零样本和三样本的主测试成本沿用 `outputs/metrics/qwen_3b_cost.json`。本地推理不写 API 单价。解析规则与第 3 步相同：解析失败则该条预测为空；非法类型或非法下标不进入计分；表面不一致仍按三元组计分并另记次数。

## 本步不做

- GlobalPointer、1.5B、Qwen3、bootstrap、改提示正文、改 `max_new_tokens`
- 重跑主测试上的零样本或三样本
- 在三种调参集预测未完整时做选择，或在中断后把 1,500 条改成子集
- 在主测试或看到分数之后更换示例
- 改 `split_manifest.json`、重抽数据、重训 BERT
- 把解析失败的输出改写成正确答案
- 报告里的结论句和错误归因正文

## 输入与输出

| 路径 | 动作 |
| --- | --- |
| `configs/qwen_3b.yaml` | 读，模型、生成参数和提示正文 |
| `data/processed/train.json` | 读，只取上述示例 |
| `data/processed/tune.json` | 读，三种条数各生成一次 |
| `data/processed/test.json` | 仅当单样本入选时读，并只生成一次 |
| `outputs/metrics/qwen_3b.csv` | 仅在选择完成之后读，用于沿用零样本或三样本的主测试行 |
| `outputs/metrics/qwen_3b_cost.json` | 仅在零样本或三样本入选后读，沿用该次主测试的延迟和 token |
| `configs/qwen_shot_count.yaml` | 写，上述预设 |
| `outputs/predictions/qwen_shot_{0,1,3}_tune.json` | 写，调参集金标、预测和原始输出 |
| `outputs/metrics/qwen_shot_count_tune.csv` | 写，三行 `qwen_shot_0`、`qwen_shot_1`、`qwen_shot_3` |
| `outputs/metrics/qwen_shot_count_cost.json` | 写，调参集平均延迟、输入 token、输出 token、解析失败、无效实体、表面不一致 |
| `outputs/metrics/qwen_shot_count_selection.json` | 先写，入选条数、调参集分数、主测试分数将读取的文件；主测试数字在该文件就绪后填入，入选条数不改 |
| `outputs/predictions/qwen_3b_one.json` | 仅当单样本入选时写 |
| `outputs/metrics/qwen_3b_one.csv` | 仅当单样本入选时写，一行主测试指标 |
| `outputs/metrics/qwen_3b_one_cost.json` | 仅当单样本入选并完成主测试生成时写，平均延迟、输入 token、输出 token、解析失败、无效实体、表面不一致 |
| `outputs/logs/qwen_shot_count.log` | 写，参数、示例编号、条数、是否重新生成主测试 |

CSV 列与词典基线相同：`method,precision,recall,micro_f1,tp,fp,fn`。

第二条从调参集预测文件重算 tune CSV，并核对选择文件里的入选条数和调参集分数。若存在 `outputs/predictions/qwen_3b_one.json`，再从该文件重算 `qwen_3b_one.csv` 和 `qwen_3b_one_cost.json`，并核对选择文件里填入的主测试数字。不得重新生成。

1,500 条乘 3 种条数。按第 3 步主测试的平均延迟估计，8GB 显卡上大约要十小时。中断后续跑未完成的预测，已完成的样本不重新生成。三种条数的调参集预测都完整之前不做选择。若要改成子集，先改本计划再确认。看到分数后不缩减调参集，也不重跑主测试。
