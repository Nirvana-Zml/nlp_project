**状态：** 待确认，未实现

**对应交付：** 课程任务书「演示录屏」：真实跑一遍系统，至少展示一个难例，画面中可见学号与姓名；提交时视频不超过 2 分钟，录屏文件不进仓库、不进 zip，只填网盘链接。

本方案先满足「真实跑系统 + 难例可视化」。2 分钟剪辑放到实现并彩排之后。学号和姓名不写进代码，录制时在页面侧栏填写。不代录屏。

现有 120 秒分镜仍在 [录屏分镜.md](录屏分镜.md)。本方案确认并实现前，不替换那份分镜。

## 页面

一个 Streamlit 页面 `app.py`。启动命令：

```text
D:/programdata/anaconda_envs/envs/medical_ner/python.exe -m streamlit run app.py
```

侧栏始终显示学号和姓名，录屏时留在画面里。页面只做实体抽取，不做诊断、治疗或用药建议。

四块内容：

1. **片头。** 题目「中文医疗实体抽取」。
2. **现场抽取。** 文本框默认填入 `outputs/errors/examples.json` 里「边界错误」那条的 `text`。方法可选：词典最长匹配、BERT-BIO、Qwen 零样本、Qwen 单样本、Qwen 三样本。点击「抽取」后走现有代码路径。画面出现加载或推理进度，以及本次延迟。
3. **难例对照。** 原文按实体类型着色。并排列出本次 `pred` 和该条的 `gold`。文本仍是默认难例时，标出类别「边界错误」，并标出相交但起止不同的实体对。区间按左闭右开。
4. **已有评测。** 只读展示主测试 CSV 的 Precision、Recall、Micro-F1。文件是 `outputs/metrics/dictionary_baseline.csv`、`outputs/metrics/bert_bio.csv`、`outputs/metrics/qwen_3b.csv`、`outputs/metrics/qwen_3b_one.csv`。页面不写哪一个更好。



## 方法


| 方法               | 现场行为                          | 配置或代码                                                      |
| ---------------- | ----------------------------- | ---------------------------------------------------------- |
| 词典最长匹配           | 不加载模型，对当前文本当场匹配               | `src/baselines/dictionary_ner.py`                          |
| BERT-BIO         | 第一次点击时加载已有 checkpoint，之后留在会话里 | `configs/bert_bio.yaml`，`scripts/train_bert_bio.py` 中的预测路径 |
| Qwen 零样本、单样本、三样本 | 第一次点击时按 4bit NF4 加载，之后留在会话里   | `configs/qwen_3b.yaml`，`src/models/qwen_prompt.py`         |


单条已记录延迟（模型已在显存中之后）：Qwen 零样本约 6.4 秒，单样本约 10.7 秒，三样本约 10.5 秒。出处是 `outputs/metrics/qwen_3b_cost.json` 与 `outputs/metrics/qwen_3b_one_cost.json` 的 `mean_latency_sec`。冷启动加载另计，不包含在上述数字里。BERT 单条延迟本仓库没有成本文件。

## 约束

- 抽取结果只显示在页面上，不回写 `outputs/predictions/`，不改 `split_manifest.json`，不改指标文件。
- 加载失败就停止，不换精度，不缩小文本。
- 难例默认锁定「边界错误」那条，不虚构错误，不手工修改预测。
- 不把模型权重、API Key、录屏文件打进提交包。



## 录制顺序

1. 打开页面，侧栏填入学号和姓名。
2. 对默认难例原文选择一种方法，点击「抽取」，等到结果和高亮出现。需要对照时再换方法各抽一次。
3. 展示 gold 与 pred 的边界差异。
4. 切到已有评测表。

提交前把成片剪到不超过 2 分钟。画面里仍须看见学号、姓名、一次真实抽取和这个难例。

## 演示操作步骤

页面实现前不能按本节操作。实现后从仓库根目录开始。

### 录前

1. 关掉通知和无关窗口。浏览器只留演示页，字体放大到录屏里能看清实体高亮。
2. 确认难例文件在：`outputs/errors/examples.json`，其中有 `category` 为「边界错误」的一条。不要改这条的 `text`、`gold`、`pred`。
3. 用 `Win + G` 打开 Xbox Game Bar，先不要按录制。

### 启动

在仓库根目录执行：

```text
cd /d D:\programdata\nlp_project
D:/programdata/anaconda_envs/envs/medical_ner/python.exe -m streamlit run app.py
```

浏览器打开页面后，看页眉是否为「中文医疗实体抽取」。侧栏填入学号和姓名，填完不要再挪开，整段录屏都要看得见。

文本框应已是「边界错误」那条原文。不要改字，不要粘贴别的句子。

### 建议先彩排再录

彩排时按下面顺序各点一次，确认能出结果。正式录屏可以只保留词典、BERT 和一种 Qwen，避免冷启动占满画面。

1. 方法选「词典最长匹配」，点击「抽取」。这一步不加载模型，应很快出现高亮、`pred` 和本次延迟。
2. 方法改成「BERT-BIO」，再点「抽取」。第一次会加载 checkpoint，等进度结束。不要中途刷新页面，否则会话里的模型会丢掉。
3. 方法改成「Qwen 零样本」（或单样本、三样本中的一种），再点「抽取」。第一次按 4bit NF4 加载。加载失败就停，不要改精度，也不要换一段更短的文本。
4. 看难例对照：原文着色、`gold` 与本次 `pred` 并排，并标出「边界错误」和相交但起止不同的实体对。
5. 滚到已有评测表，确认能看到 Precision、Recall、Micro-F1。不要在口播里说哪个方法更好。

### 正式录屏

1. 彩排里已经加载过的页面不要关。模型还在会话里时再按 `Win + Alt + R` 开始录。
2. 镜头先停在页眉和侧栏，让学号、姓名、题目同时出现。
3. 对默认原文点一次「抽取」。优先点词典或已经加载好的 BERT，让画面出现进度、结果高亮和延迟。
4. 鼠标指到 gold 与 pred 不一致的那一对实体，停几秒。
5. 若还要展示第二种方法，再选 BERT 或一种 Qwen，点「抽取」，等到新的高亮出现。
6. 滚到评测表，让四份 CSV 对应的指标行进入画面，然后停止录制。

### 录后

1. 成片剪到不超过 2 分钟。剪完仍须看见学号、姓名、一次真实抽取和这个难例。
2. 视频上传网盘。链接填进报告封面的「演示录屏」，并填进金山文档收集表。
3. 视频不要放进仓库，也不要打进提交 zip。
